CODECHECK validation rules, specification 1.0

The 59 rules that CODECHECK tooling applies to a codecheck.yml, its bundle, the certificate and the register entry, for version 1.0 of the configuration file specification (published 2020-02-06; rules updated 2026-10-02). The rule file is the source of truth; see RULES.md for the identifier scheme.

This specification version is superseded by 2.0, but remains in use by existing certificates.

Severity follows the specification's RFC 2119 keywords: error for MUST, warning for SHOULD, info for MAY or advice. Other versions: 2.0
